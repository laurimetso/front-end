# Portfolio Website

**main has the exercise materials and projekti-branch has the actual project. Both can be opened with Live Server.**
This is a simple static portfolio website built with HTML, CSS, and JavaScript.

## Requirements

- Visual Studio Code
- A modern web browser (Chrome, Edge, Firefox, etc.)

## Recommended VS Code Extensions

- **Live Server**

## How to open the project in VS Code

1. Download and install Visual Studio Code if you don't already have it:
   - https://code.visualstudio.com/
2. Open VS Code.
3. Choose `File` > `Open Folder...`.
4. Select the project folder

## How to run the website locally

1. Install the Live Server extension in VS Code.
2. Open the project folder.
3. Open `index.html`.
4. Click the `Go Live` button in the VS Code status bar.
5. Your site will open in the browser, usually at `http://127.0.0.1:5500/dist/index.html`.

## Notes

- This project does not need a build step.
